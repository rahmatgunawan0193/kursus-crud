# Tahap 4 - Front-end Dinamis

## Cara menjalankan
Salin ke htdocs/kursus. Buka http://localhost/kursus/ (beranda), daftar ke sebuah kursus, lalu lihat pendaftar.php.

Tautan menu Admin langsung ke dashboard (belum ada login).

## File BARU pada tahap ini (ketik / buat)
- `daftar.php`
- `index.php`
- `pendaftar.php`

## File yang DIUBAH dibanding tahap sebelumnya
- `partials/header.php`

Tips: bandingkan dengan tahap sebelumnya memakai perintah `git diff tahap-3-backend tahap-4-frontend --stat` atau fitur Compare di VS Code.
